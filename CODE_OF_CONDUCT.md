# Code of conduct

This is a small hobby project run by volunteers who like old hardware.

* Be kind. Assume good faith. Remember the person on the other side of
  the issue tracker may be new to BLE, Python or English.
* Argue about bytes, not about people. Protocol claims are settled with
  captures, not volume.
* Harassment, discrimination or personal attacks are not tolerated, in
  issues, pull requests, or anywhere else this project operates.
* Maintainers may edit, lock or remove content and may block contributors
  who repeatedly break these rules.

If something happened that you want a maintainer to look at, open a
private security advisory on the repository (it reaches only the
maintainer) or mention @kengggg in the thread.
